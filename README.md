## Snapshot

Robotics engineering student at THWS, Germany, specializing in real-time embedded systems, low-latency neural data pipelines, and mechatronic control loops. Developer of Reduino and Project BrainDance. Experienced in production software infrastructure through full-stack framework development at Audi AG.

---

## Technical Focus Areas

### Neuro-Robotics and Real-Time Signal Processing
* **Project BrainDance:** Directing an independent brain-computer interface research project backed by a 7500 EUR prototyping grant from the German Federal Ministry of Education and Research (BMBF) and the DAAD. 
* **Data Pipelines:** Engineering multi-threaded real-time neural data ingestion pipelines using the BrainFlow library to sample 16-channel EEG data from OpenBCI Ultracortex Mark IV hardware.
* **Algorithmic Stack:** Implementing digital preprocessing stages including spatial Laplacian filtering, Common Spatial Patterns (CSP), and sliding-window Fast Fourier Transforms to extract event-related desynchronization features for a hybrid CNN-LSTM-MLP motor imagery classifier.

### Embedded Systems and Compiler Architectures
* **Reduino:** Architected an open-source Python-to-C++ cross-compiler with 130+ GitHub stars, allowing high-level programmatic execution loops to be deployed directly onto memory-constrained 8-bit and 32-bit microcontrollers with near-zero flash memory overhead.
* **Low-Power Firmware:** Experienced in writing register-level bare-metal firmware, watchdog timer manipulation for micro-amp power-down states, and building custom C++ linear algebra libraries for real-time Cartesian space robotic controllers.

### Open-Source Infrastructure
* **RedDownloader:** Maintained and scaled a Python media integration library to over 160 stars on GitHub, managing packaging, dependency trees, and community open-source feature contributions.
